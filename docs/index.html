How it works. Each node is a vantage point with a radius μ (the median distance to the sequences below it). Sequences within μ go to the left (inside) branch, the rest to the right (outside). Distance is the number of mismatching bases (Hamming). If the read is at distance d from a vantage point and we already know a match within τ, the triangle inequality says the outside branch can be skipped when d + τ < μ and the inside branch when d − τ > μ. Skipped branches are the saving.
